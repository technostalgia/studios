# Technostalgia Studios

Static studio-site prototype with an encrypted committee listening room.

Publish from the main branch root using GitHub Pages. No custom domain is configured.

The source archive contains the React/Vite implementation. Audio files and the access manifest are encrypted. No original WAVs or vocal files are included. The temporary access code should be replaced before sensitive material is added.
